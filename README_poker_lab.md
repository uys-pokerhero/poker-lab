# Uys Poker Lab

## About Me & Goal

Hi, I'm Uys.

This repo is my Poker Lab. I'm at the start of my focused poker journey.

My overall goal for 2026:
- Become a winning cash and tournament player with a win rate of ≥ +5 bb/hour.
- Maintain a stable bankroll.
- Keep a balanced life (health, faith, relationships, finances, work).
- Commit to roughly 1,000 hours of poker (about half study, half play).

I use:
- Gemini as performance / data / systems analyst (Google Sheets & dashboards),
- ChatGPT as my primary coach & drill partner,
- Claude as my research summariser & playbook editor,
- Cursor as my technical lab (this repo),
- GTO Wizard as my main GTO reference and drill tool.

This repo will contain code, sims, tools, and experiments that make me a stronger poker player.

## Tech Stack & Coding Preferences

- Languages: Python + TypeScript/React (possible Next.js later for websites)
- Style:
  - Clear, descriptive function and variable names
  - Type hints and docstrings in Python
  - Small, focused modules
  - One small, complete feature at a time
- Quality:
  - Prefer readability over cleverness
  - Include basic tests or at least examples
  - Explain non-trivial code in comments or markdown

## Role of the AI Assistant (Cursor)

When I talk to the AI in Cursor, I want it to:

1. Propose minimal designs before writing lots of code.
2. Generate clean, well-structured code following the style above.
3. Help me debug and test code step by step.
4. Explain code in plain language when I ask.
5. Help me keep things simple and incremental, not over-engineered.

If I'm vague, ask at most two clarifying questions, then suggest a small, concrete next step.
